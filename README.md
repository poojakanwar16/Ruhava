# 🛍️ Ruhava

A full-stack e-commerce web application built with Django that provides a complete online shopping experience for customers and an efficient product management system for shopkeepers.

## ✨ Features

### Customer
- User Registration & Login
- Email OTP Verification
- Browse Products
- Product Details
- Wishlist
- Shopping Cart
- Buy Now
- Checkout
- Order Placement
- Product Reviews

### Shopkeeper
- Add Products
- Edit Products
- Delete Products
- Upload Product Images
- Manage Categories
- Stock Management

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/poojakanwar16/Ruhava.git
```

Create a virtual environment

```bash
python -m venv .venv
```

Activate it

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run migrations

```bash
python manage.py migrate
```

Start the server

```bash
python manage.py runserver
```
